[DB host fix] Invalid default hostname `MySQL`
- `mvp/lib/data.php`: if `DB_HOST` is unset, default host is `127.0.0.1`; literal `MySQL` (design-doc label) maps to `127.0.0.1`.
- `config/app.php`: same logic for `storage.db.host`.
- Rationale: PDO cannot resolve host name `MySQL`; production PHP was falling back to JSON. After deploy, set real `DB_HOST` if DB is not on loopback (e.g. private IP or `host.docker.internal`).

[DB port / tunnel] plink reverse forward uses **3306** on the server
- User tunnel: `plink -N -i "...ppk" jjames@desktopmasters.com -P 2211 -R 0.0.0.0:3306:127.0.0.1:3306`
- Meaning: SSH **server** listens on **3306**; traffic is forwarded to **127.0.0.1:3306 on the machine running plink** (developer PC). MySQL must run locally on 3306 on that PC while the tunnel is up.
- App default `DB_PORT` updated from **3308** to **3306** in `mvp/lib/data.php`, `config/app.php`, `scripts/db-smoke.mjs`.
- Added `scripts/db-reverse-tunnel.cmd` using `DESIGN SPECS\plink.exe` + `jjames at DesktopMasters.com.ed25519.ppk`.
